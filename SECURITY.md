# Security policy

## Reporting a vulnerability

Do not post credentials, pairing material, private camera URLs, or an
unredacted Home Assistant backup in a public issue.

For a public protocol or code issue that contains no secrets, open a GitHub
issue. For a vulnerability that could expose credentials or remotely control
an oven, use GitHub's private vulnerability reporting after the repository is
published.

Please include the affected version, impact, and a minimal reproduction with
all personal data and credentials removed.

## Supported versions

Security fixes are provided for the latest published release.
